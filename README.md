# Skibidi vs Ohio – Mini Invaders

A small browser game inspired by Space Invaders. Choose a side and shoot the enemies before they reach you.

## Features

- Playable characters: "Skibidi" and "Ohio" (selectable from the UI)
- Canvas-based gameplay 
- Controls: move left/right and shoot
- New UI features added:
  - Restart — restart the current game or reload if the reset function isn't available
  - Super Shot — fires a short burst (three shots) as a special move
  - Auto-Fire — toggle automatic continuous firing
- Accessibility: banner area with aria-live for important messages, canvas has an aria-label

## Controls

- Move: Left/Right arrow keys or A / D
- Shoot: Space
- UI buttons: Select character, Restart, Super Shot, Auto-Fire toggle

## How to run

- Open index.html in your browser 
- Or run a static server (for example Live Server in VS Code) and open the served URL.

## Files

- index.html — main markup and UI
- script.js — game logic (player, waves, shooting, loop)
- style.css — styles
