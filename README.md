# Form Overload

A small interactive UI demo titled "Form Overload" for Week 1: Worst UI Design.

## Description

The app displays a single framed stage with a prominent title and a large CTA button. It's intended as a playful example of poor UI design (overstated copy, aggressive CTA).

## How to run

- Open index.html in your browser (file path: index.html in the project root).
- Optionally serve the folder with a static server for local development.

## Files

- index.html — main markup and the CTA button
- style.css — visual styling for the frame, title, and button
- script.js — interactive behaviors (button handlers and any animations)

## Feature

- This Application is also interactive, it requires users to answer meme questions while the forms overload the the screen the more they answer the more the screen is filled.
